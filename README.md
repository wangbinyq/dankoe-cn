# Dan Koe 中文译文库

Dan Koe 的免费通讯（letters.thedankoe.com）中文翻译合集，共 74 篇。

- 首页 `index.html`：按时间倒序的目录，可搜索，点开直接读译文
- `articles/<slug>.html`：每篇译文一个文件，slug 与原文链接一致
- 付费文章没有收录；原文里的作者推广段落以说明行略过

原文版权归 Dan Koe 所有，这里是个人学习用的翻译，不是官方版本。每篇文末都有原文链接。

## 本地查看

```sh
python3 -m http.server 8000
```

然后打开 http://localhost:8000/

## 说明

- 译文按发布时间从新到旧排列
- 目录页是一次性生成的静态 HTML，没有构建步骤，也不需要 JS 框架
- 深色模式跟随系统设置
